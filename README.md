## О проекте

Проект представляет собой Java-приложение с графическим интерфейсом, моделирующее движение змейки внутри окна.

При запуске направление движения выбирается случайным образом. При достижении границы окна направление изменяется по принципу отражения. Пользователь может регулировать скорость движения, ставить приложение на паузу и перезапускать движение.

Проект создан в рамках курсовой работы и демонстрирует применение Java, JavaFX, Gradle, автоматического тестирования, логирования и документации.

## Возможности

- **Случайное направление движения** при запуске.
- **Отражение от границ окна** по закону отражения.
- **Регулировка скорости** с помощью пользовательского ползунка.
- **Пауза и продолжение** движения.
- **Перезапуск** приложения.
- **Графическое отображение** движения змейки средствами JavaFX.
- **Логирование** событий приложения в консоль и файл.
- **Unit-тесты** логики модели на JUnit 5.
- **JavaDoc** для документирования исходного кода.

## Требования

Перед запуском установите:

- JDK 17 или новее;
- IntelliJ IDEA или другую IDE с поддержкой Gradle.

Для запуска Gradle-команд используйте Gradle Wrapper, если он присутствует в репозитории. Это позволяет запускать сборку без отдельной установки Gradle.

## Запуск

### IntelliJ IDEA

1. Клонируйте репозиторий и откройте его в IntelliJ IDEA.
2. Импортируйте проект как Gradle-проект.
3. Дождитесь загрузки зависимостей.
4. Запустите задачу `run` в панели Gradle.

### Через терминал

Перейдите в корневую папку проекта.

**Windows:**

```bat
gradlew.bat run
```

**Linux / macOS:**

```bash
./gradlew run
```

Если Gradle Wrapper отсутствует, используйте установленный Gradle:

```bash
gradle run
```

## Тестирование

Для запуска unit-тестов выполните:

**Windows:**

```bat
gradlew.bat test
```

**Linux / macOS:**

```bash
./gradlew test
```

Или при установленном Gradle:

```bash
gradle test
```

HTML-отчёт Gradle после выполнения тестов находится в:

```text
build/reports/tests/test/
```

## Сборка

Чтобы очистить предыдущие результаты сборки и собрать JAR:

**Windows:**

```bat
gradlew.bat clean jar
```

**Linux / macOS:**

```bash
./gradlew clean jar
```

При установленном Gradle:

```bash
gradle clean jar
```

Собранный файл будет находиться в каталоге:

```text
build/libs/
```

> Приложение использует JavaFX. Для запуска собранного JAR вне Gradle необходимо корректно настроить JavaFX runtime и параметры модулей. Для разработки и демонстрации рекомендуется запускать приложение через `run`.

## JavaDoc

Для генерации HTML-документации выполните:

**Windows:**

```bat
gradlew.bat javadoc
```

**Linux / macOS:**

```bash
./gradlew javadoc
```

Документация создаётся в:

```text
build/docs/javadoc/
```

Откройте `index.html` в браузере.

## Логирование

В проекте используется Log4j2.

События приложения выводятся в консоль и записываются в файл:

```text
logs/snake.log
```

Конфигурация логирования:

```text
src/main/resources/log4j2.xml
```
